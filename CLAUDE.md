# Project rules — eks-argo-bootstrap

## Public-repo invariant (HARD)

This is a **public** repo. No file may contain:
- Real AWS account IDs (12-digit sequences)
- Real role/policy/queue/bucket ARNs
- Real OIDC issuer URLs (`oidc.eks.<region>.amazonaws.com/id/...`)
- Real VPC / subnet / security-group / IGW / NAT / ENI IDs
- Real domain names tied to a specific tenant

CI enforces this via two `grep` steps in `.github/workflows/validate.yaml` (mandatory issue regex + defense-in-depth ERE patterns). Workers MUST run the sanitization grep locally before committing.

If you need account-specific data at runtime, reference it via `{{metadata.annotations.<key>}}` from the in-cluster Secret. Never hardcode.

If you find a real value already committed, **stop, do NOT amend, do NOT push** — file a finding in your run result and let the human rotate the credential before any history is rewritten.

## ApplicationSet contract — one canonical shape

Every chart's delivery follows the shape in `bootstrap/applicationsets/cert-manager.yaml`. Do not invent variations (no Git generator, no list generator, no SCM generator). Copy + parametrize:
- `chart`, `targetRevision` (pinned `v*.*.*`)
- `template.metadata.annotations.argocd.argoproj.io/sync-wave`
- `destination.namespace`
- `helm.releaseName` (explicit, NOT default-derived)
- `valueFiles` to `$values/charts/<chart>/values.yaml`
- `valuesObject` for annotation-templated values (IRSA, region, cluster name)

## Annotation templating idiom

The 13 cluster Secret annotations are accessed via `{{metadata.annotations.<key>}}` (NOT `{{values.<key>}}`). The cluster generator's `values:` block is a separate intermediary mechanism and is NOT used in this repo unless explicitly chosen — direct annotation access is the project standard.

Example (in an ApplicationSet's `template.spec.sources[].helm.valuesObject`):

```yaml
serviceAccount:
  annotations:
    eks.amazonaws.com/role-arn: '{{metadata.annotations.alb_role_arn}}'
clusterName: '{{metadata.annotations.cluster_name}}'
region: '{{metadata.annotations.aws_region}}'
```

The issue's "valuesObject with `{{values.X}}` templating" wording was loose shorthand. The canonical pattern (per AWS Blueprints reference) is `{{metadata.annotations.X}}`.

## Toleration discipline

The bootstrap nodegroup `system-ng` carries taint `CriticalAddonsOnly:NoSchedule`. Every Deployment **and Helm post-install Job** for charts in this repo that target the bootstrap nodegroup MUST include:

```yaml
tolerations:
  - key: CriticalAddonsOnly
    operator: Exists
```

Apply at every Deployment-controlling values key the chart exposes (varies per chart — read the chart's upstream `values.yaml` for the FULL list before adding). cert-manager has FOUR keys: `tolerations` (controller), `webhook.tolerations`, `cainjector.tolerations`, `startupapicheck.tolerations` (the post-install Job — missing this hangs install).

## Pinned versions, no exceptions

Every Helm `targetRevision` MUST be a pinned version string (e.g. `v1.20.2`). Forbidden: `*`, `HEAD`, empty, latest.

The values-ref source's `targetRevision` may be `HEAD` for development; **set to a tag/SHA before any production cut.** This is a standing TODO for the prod-readiness pass.

## Sync waves

See `docs/sync-waves.md`. Use the registry; don't introduce new waves without updating the doc.

**Honest constraint:** sync-wave on an Application object generated by an ApplicationSet is advisory only — without an app-of-apps wrapper, all Applications sync in parallel. ArgoCD's retry semantics handle ordering races. Do not preemptively add a wrapper unless retry noise materially bites in production.

## Repo URL

`bootstrap/applicationsets/*.yaml` hardcodes `repoURL: https://github.com/slikk66/eks-argo-bootstrap` for the values-ref source. Forks must search-replace; this is documented in `README.md`. Do NOT add a 14th annotation to eks-pulumi — that contract is locked at 13.

## Testing

Local pre-PR checks (run all four; CI runs them too):

```bash
kustomize build bootstrap/ > /tmp/rendered.yaml
kubeconform -strict -summary -ignore-missing-schemas \
  -schema-location default \
  -schema-location 'https://raw.githubusercontent.com/datreeio/CRDs-catalog/main/{{.Group}}/{{.ResourceKind}}_{{.ResourceAPIVersion}}.json' \
  -kubernetes-version 1.35.0 /tmp/rendered.yaml
grep -RIn 'arn:aws:iam::[0-9]\{12\}\|[0-9]\{12\}\.dkr\.ecr' . --exclude-dir=.git --exclude-dir=.dangeresque
# Defense in depth (broader ARN / OIDC / network ID patterns) — see .github/workflows/validate.yaml
```
