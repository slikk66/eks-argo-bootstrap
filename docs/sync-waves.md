# Sync wave registry

ArgoCD sync waves order resources within an Application's sync. Lower wave = earlier. The annotation is `argocd.argoproj.io/sync-wave: "<int>"`.

## Cross-Application ordering caveat (HONEST)

ApplicationSets generate independent Applications. Sync waves applied to the **Application object** (via `template.metadata.annotations` in the ApplicationSet) only order child Applications inside an app-of-apps wrapper Application. **Without such a wrapper, all Applications generated by ApplicationSets sync in parallel.**

For Slice 1, sync-wave annotations on the Application object serve as **documented intent / registry metadata**. Runtime ordering between e.g. cert-manager (-10) and aws-load-balancer-controller (0) is mitigated by ArgoCD's retry semantics — the ALB webhook race vs cert-manager resolves in 1-2 reconcile cycles. **This is canonical and matches the AWS Blueprints reference.**

If retry noise materially bites in production, address with a targeted app-of-apps wrapper. Do not preemptively complicate the canonical ApplicationSet pattern.

## Registry

| Wave | Chart | Rationale |
|---|---|---|
| -10 | cert-manager | Webhooks for ALB controller and other controllers depend on cert-manager CA. |
| -5  | karpenter (controller + CRDs) | Data plane (NodePool/EC2NodeClass at wave 5) needs the controller alive. |
|  0  | aws-load-balancer-controller | Standard addon, no explicit predecessors after cert-manager. |
|  0  | external-secrets | Pulls AWS SecretsManager via IRSA; no explicit predecessors. |
|  0  | aws-ebs-csi-driver | Storage provisioner; runs alongside other addons. |
|  0  | aws-efs-csi-driver | Storage provisioner; runs alongside other addons. |
|  0  | metrics-server | Standard addon. |
|  0  | adot-collector | Telemetry. |
|  0  | fluent-bit | Log shipper. |
|  0  | argocd (self-managed) | ArgoCD manages itself; usual pattern. |
|  5  | karpenter NodePool + EC2NodeClass | Depends on karpenter controller being healthy. |

## Adding a new wave

If your chart doesn't fit a slot, propose a new wave in your run result. Do not silently introduce new wave numbers — they need to be coordinated across all charts.
